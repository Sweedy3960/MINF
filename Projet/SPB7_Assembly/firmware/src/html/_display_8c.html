Detailed Description

DISPLAY.c

Module de gestion de l'affichage du TPA

Author
J. Jose Moreno
Date
16.04.2020
Version
1.0

Description

Fournit les fonctions necessaires pour afficher les donnees du TPA/VPA sur l'ecran LCD du TPA. Display_Task effectue une mise a jour reguliere de l'affichage complet a partir d'une copie complete locale. Elle utilise l'API OpenSource ugui.h. pour dessiner des formes et du texte sur l'ecran graphique.
