Fournit les fonctions necessaires pour afficher les donnees du TPA/\+VPA sur l\textquotesingle{}ecran LCD du TPA. Display\+\_\+\+Task effectue une mise a jour reguliere de l\textquotesingle{}affichage complet a partir d\textquotesingle{}une copie complete locale. Elle utilise l\textquotesingle{}API Open\+Source \doxylink{ugui_8h}{ugui.\+h}. pour dessiner des formes et du texte sur l\textquotesingle{}ecran graphique.
